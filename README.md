# Article Dashboard

Instruksi singkat untuk menjalankan proyek ini secara lokal (Windows).

## Langkah instalasi dan jalankan
1. Clone repository:
````powershell
https://github.com/pavellsan8/sharing_vision_ui.git
cd "sharing_vision_ui"
````

2. Install dependency:
````powershell
npm install
````

3. Jalankan dev server:
````powershell
npm start
````
